# Simple Image Classification

This is a project which investigates image classification tools on the CIFAR-10 dataset. The full notebook and other code is included here. This project revealed higher accuracy in unique classes, for example, Class 0 performed quite well, due to its uniqueness compared to the other classes, with the rest of the classes including animals. Understandable the rest of the classes were harder to predict, as there were a lot of similarities visually, especially between dogs and cats.
